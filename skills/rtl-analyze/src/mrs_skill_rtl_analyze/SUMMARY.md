## 一句话概述

一个 RTL 代码的"读、审、核、写、档"全链路 skill——读代码出报告（A）、审代码质量（B）、核对文档与代码一致性（C）、写代码（D）、从代码逆向生成与维护文档（E），内核通用、领域可插拔、约定按项目加载。

## 五个模式

| Mode | 方向 | 触发词 | 功能 |
|------|------|--------|------|
| **A** 分析代码 | 读代码 | 分析代码 / analyze module | 单模块深度分析：端口、参数、时钟域、FSM、数据通路、PPA 估计，输出分析报告 + Mermaid 图 |
| **B** 评审代码 | 读代码 | 评审代码 / code review | 代码质量审计：编码风格、latch、FSM、CDC、综合就绪、结构、PPA、DFT、领域专项，输出 severity 分级问题清单 |
| **C** 评审文档 | 读文档+读代码 | 评审文档 / cross-check doc | 文档 ↔ RTL 交叉核对：信号名、位宽、参数、模块层次、时钟域、Mermaid 图、FSM、交叉引用、时序协议是否与代码一致 |
| **D** 写代码 | 写代码 | 写代码 / write RTL / 重构 | 生成、修改、优化、重构 RTL；先 Grep 项目同类模块复用风格，再按约定产出可综合代码 + 架构图 + PPA 估计 + 合规清单 |
| **E** RTL→文档 | 读代码+写文档 | 逆向文档 / 文档对齐 / 增量更新文档 | 从 RTL 生成设计文档：E-1 逆向补档 / E-2 漂移对齐 / E-3 增量更新；只提取事实，设计意图标【待确认】交还 |
