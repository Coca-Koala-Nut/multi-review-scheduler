Claude Code skill：A 读码出报告、B 审码质量、C 核对文档↔代码、D 写码、E 从码逆向生成与维护文档。主框架 ASIC/FPGA 通用，领域专项按项目关键词叠加。触发 /rtl-analyze <路径> 或自然语言含"分析代码/评审代码/写RTL/逆向文档"等关键词；可被其他 skill 经 Skill() 调用。

1 五个模式：按"读/写 × 代码/文档"定位

读=读取不改、写=生成修改、—=不涉及。D 是唯一改代码的，E 是唯一改文档的；歧义时默认走 Mode A 并标注，不反问。

模式 触发词 对代码 对文档 功能 & 产出
A 分析 分析代码 / analyze module 读— 单模块深度分析：端口/参数/时钟域/复位/FSM/数据通路/寄存器/子模块/Mermaid 图/PPA 估计（A-1~A-12）→ 分析报告
B 评审 评审代码 / code review 读— 9 大类审计：编码风格/latch/FSM/时钟复位CDC/综合就绪/结构正确/PPA/DFT/领域专项 → severity 分级清单 + checklist 汇总
C 核对 评审文档 / cross-check doc 读读 文档↔RTL 交叉核对 12 类：完整性/信号名/位宽/参数/层次/时钟域/Mermaid 图/FSM/交叉引用/时序协议/死链/文档质量
D 写码 写代码 / write RTL / 重构 写— 生成/修改/优化/重构 RTL；先 Grep 项目同类模块复用风格 → 可综合代码 + 架构图 + PPA 估计 + 合规清单
E 逆向档 逆向文档 / 文档对齐 / 增量更新文档 读写 E-1 逆向补档 / E-2 漂移对齐 / E-3 增量更新（+E-0 共用约束）；只提取代码事实，设计意图标【待确认】交还

3 关键约束 & 调用语义

Mode E 事实优先

只描述代码已实现的事实，设计意图标 【待确认】 交还设计者，绝不编造。

Mode D 先搜后写

写码前必须 Grep 项目同类模块；搜到复用风格、搜不到才用通用默认，保证新码融入项目。

PPA 必先确认工艺/器件

未指定工艺 → 绝对数值标 @unspecified process，只给相对评估，不报虚假绝对数。

Skill() 调用语义

被 ab-review 等通过 Skill() 调用时，args 必含模式关键词；歧义默认走 Mode A 并标注，不反问（保护调用方自动流程）。

输出语言跟随来源

用户直接交互 → 跟随 prompt 语言；被 Skill() 调用 → 跟随调用方（ab-review 默认中文，使 B 意见能直接落入 b-round 而不污染下游文档语言）。

纯规范型，无脚本

skill 目录仅 SKILL/README/SUMMARY，无脚本依赖；改检查清单/格式后按 SKILL.md 末尾"维护说明"5 步人工回归验证。
